# NEON//DODGE — Cyber Arcade

A premium browser mini-game concept focused on polished visual design and responsive Canvas gameplay.

## Core
Dodge neon hazards, collect energy cores, activate slow-motion, survive escalating levels and beat your persistent high score.

## Stack
HTML5 · CSS3 · Vanilla JavaScript · Canvas API · LocalStorage

## Features
- Progressive difficulty
- Score, level and multiplier HUD
- Energy core slow-motion power-up
- Particle effects and neon visuals
- Pause / restart states
- Persistent high score
- Responsive arcade interface
- No framework or game engine

## Run
Open `index.html`, or use `python -m http.server 8000`.
